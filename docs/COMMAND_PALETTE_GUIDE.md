# Command Palette - User Guide

## What is the Command Palette?

The Command Palette is a powerful keyboard-first interface that allows you to quickly navigate and execute actions in the application. It's similar to the command palettes found in modern apps like Linear, Notion, and GitHub.

## How to Open

Press `Cmd+K` (Mac) or `Ctrl+K` (Windows/Linux) anywhere in the application.

## How to Use

1. **Open the palette**: Press `Cmd+K` / `Ctrl+K`
2. **Navigate**: Use arrow keys `↑` `↓` or type to search
3. **Execute**: Press `Enter` to run the selected command
4. **Close**: Press `Esc` or click outside

## Available Commands

### 📍 Navigation
- **Dashboard** - Go to your project dashboard

### 📁 Recent Projects
The palette shows your 5 most recently updated projects for quick access.

### ⚡ Actions (Global)
- **Create Project** `⌘N` - Start a new project
- **Log Out** - Sign out of your account

### ⚡ Actions (Project Page Only)
These commands are only available when you're viewing a project:

- **Upload Document** `⌘U` - Upload files to your project
- **View Progress Dashboard** `⌘P` - Check project completion status
- **Generate with AI** `⌘G` - Use AI to generate content
- **Export PDF** `⌘E` - Download your project as PDF

## Tips & Tricks

### 🔍 Quick Search
Start typing to instantly filter commands and projects. The search is fuzzy, so you don't need exact matches.

### ⌨️ Keyboard Navigation
- Use `↑` and `↓` arrow keys to navigate
- Press `Enter` to execute
- Press `Esc` to cancel

### 🎯 Context-Aware
The palette shows different commands based on where you are in the app. On a project page, you'll see project-specific actions.

### 🕐 Recent Projects
Your most recently updated projects appear automatically, making it easy to jump between active work.

## FAQs

**Q: Why don't I see project-specific commands?**
A: Make sure you're on a project page. Navigate to a project first, then open the command palette.

**Q: Can I customize keyboard shortcuts?**
A: Currently, keyboard shortcuts are fixed. Custom shortcuts may be added in a future update.

**Q: Why can't I export my project?**
A: The export feature requires your project to be at least 50% complete. Check your progress dashboard.

**Q: Do I need to be online to use the command palette?**
A: Yes, the palette fetches recent projects from the server and requires an active session.

## Troubleshooting

**Command palette won't open**
- Verify you're pressing `Cmd+K` on Mac or `Ctrl+K` on Windows/Linux
- Make sure you're not in a text input field
- Try refreshing the page

**Recent projects not showing**
- Make sure you're logged in
- Check your internet connection
- Verify you have created projects

**Commands don't execute**
- Make sure you're pressing `Enter` after selecting
- Check if the command is available in your current context
- Try closing and reopening the palette
